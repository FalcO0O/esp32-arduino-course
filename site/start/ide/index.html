    3. Konfiguracja środowiska i Wokwi

    Gdy znasz już teorię oraz budowę mikrokontrolera ESP32-C6, czas przygotować narzędzia do pracy. Kod dla naszej płytki możemy pisać zarówno w środowisku fizycznym (używając darmowego Arduino IDE), jak i wirtualnym (za pomocą symulatora Wokwi). Poniżej znajdziesz instrukcję konfiguracji obu tych rozwiązań.

    Narzędzie wirtualne: Symulator Wokwi

    Jeśli nie masz jeszcze fizycznej płytki ESP32-C6, przewodów i diod, lub chcesz przetestować swój kod na szybko – Wokwi to darmowy, internetowy symulator układów elektronicznych, z którego będziemy korzystać w tym kursie.

    Dlaczego warto korzystać z Wokwi?

    • Zero instalacji: Symulator działa w przeglądarce (na komputerze, tablecie czy telefonie).
    • Brak ryzyka uszkodzenia sprzętu: Błędne połączenie zasilania nie spali rzeczywistej płytki.
    • Gotowe schematy: Na stronach ćwiczeń w tym kursie znajdziesz gotowe linki. Kliknięcie w nie otworzy wirtualną płytkę stykową z połączonymi już elementami (diodami, rezystorami czy czujnikami). Twoim zadaniem będzie jedynie dopisanie brakującego kodu i kliknięcie przycisku Start (Uruchom).

    Strona główna symulatora: wokwi.com

    Narzędzie fizyczne: Arduino IDE 2.x

    Do pracy z rzeczywistym mikrokontrolerem będziemy korzystać z najpopularniejszego środowiska dla hobbystów – Arduino IDE w wersji 2.x. Środowisko to automatycznie kompiluje Twój kod (napisany w języku C/C++) do instrukcji maszynowych i wgrywa go przez kabel USB bezpośrednio do pamięci Flash płytki.

    Krok 1: Instalacja programu

    1. Wejdź na oficjalną stronę: 🔗 arduino.cc/en/software
    2. Pobierz wersję instalacyjną dla swojego systemu operacyjnego (np. Windows Installer) i przejdź standardowy proces instalacji.

    Krok 2: Instalacja pakietu obsługi płytek ESP32

    Domyślnie Arduino IDE obsługuje tylko oficjalne płytki marki Arduino (np. UNO, Nano). Aby dodać obsługę układów firmy Espressif (w tym ESP32-C6): 1. Otwórz Arduino IDE i wejdź w Plik → Preferencje (lub wciśnij skrót Ctrl + ,). 2. Znajdź pole Dodatkowe adresy URL menedżera płytek. 3. Wklej tam poniższy link (odpowiada za pobranie oficjalnych definicji płytek od producenta): 

    https://espressif.github.io/arduino-esp32/package_esp32_index.json
    Uwaga: Jeśli masz już tam wpisane inne linki, rozdziel je przecinkiem lub dodaj w nowej linii klikając ikonę okna obok pola tekstowego. 4. Kliknij OK, aby zatwierdzić zmiany. 5. Z lewego paska bocznego wybierz ikonę Menedżer płytek (lub przejdź do: Narzędzia → Płytka → Menedżer płytek...). 6. Wyszukaj pakiet o nazwie esp32 (autorstwa Espressif Systems) i kliknij przycisk Instaluj. Pobieranie i instalacja kompilatora może zająć kilka minut.

    Krok 3: Wybór płytki i portu komunikacyjnego

    1. Podłącz swoją płytkę ESP32-C6 do komputera za pomocą kabla USB-C.
    2. Upewnij się, że kabel wspiera przesyłanie danych (niektóre tanie kable od ładowarek posiadają w środku tylko przewody zasilające i nie pozwalają na komunikację).
    3. W Arduino IDE wejdź w menu Narzędzia → Płytka → esp32 i wybierz ESP32-C6 Dev Module.
    4. Wejdź w Narzędzia → Port i wybierz port, pod którym zgłosiła się Twoja płytka (na Windowsie będzie to np. COM3 lub COM4, na Linuxie/macOS np. /dev/ttyUSB0 lub /dev/cu.usbserial).

    ⚠️ Kluczowe ustawienie: USB CDC On Boot

    Układ ESP32-C6 posiada wbudowany sprzętowy kontroler USB-JTAG/Serial. Aby monitor portu szeregowego w Arduino IDE mógł odbierać komunikaty wysyłane przez funkcję Serial.println(), musisz włączyć w opcjach odpowiednie przekierowanie.

    Aktywacja CDC

    W menu górnym przejdź do: Narzędzia → znajdź opcję USB CDC On Boot i upewnij się, że zaznaczona jest wartość Enabled. Bez tego ustawienia program wgra się poprawnie, ale w Monitorze Szeregowym nie zobaczysz żadnych napisów!

    [PLACEHOLDER: Tutaj wstaw zrzut ekranu przedstawiający opcję Narzędzia -> USB CDC On Boot -> Enabled w Arduino IDE]

    Pierwsze uruchomienie programu (Test)

    Sprawdźmy, czy cały łańcuch narzędziowy działa poprawnie. Spróbujemy wgrać pusty szkic i otworzyć komunikację szeregową.

    1. Wklej poniższy kod testowy do okna edytora: 
      void setup() {
  // Uruchamiamy port szeregowy z prędkością 115200 bodów (standard dla ESP32)
  Serial.begin(115200);
  delay(1000); // Czas na ustabilizowanie połączenia
  Serial.println("Środowisko Arduino IDE działa poprawnie!");
}

void loop() {
  Serial.println("ESP32-C6 żyje i nadaje...");
  delay(2000); // Wyślij komunikat co 2 sekundy
}
    2. Kliknij ikonę Strzałki w prawo (Wgraj) w lewym górnym rogu (lub użyj skrótu Ctrl + U).
    3. Poczekaj, aż w dolnej konsoli zobaczysz napisy informujące o kompilacji i procesie wgrywania (zakończonym komunikatem typu Leaving... Hard resetting via RTS pin...).
    4. Otwórz Monitor Szeregowy (ikona lupy w prawym górnym rogu lub skrót Ctrl + Shift + M).
    5. Upewnij się, że w prawym dolnym rogu okna Monitora wybrana jest poprawna prędkość transmisji: 115200 baud.
    6. Jeśli widzisz pojawiające się napisy "ESP32-C6 żyje i nadaje..." – Twoje środowisko jest gotowe do pracy!

    Rozwiązywanie problemów (Troubleshooting)

    1. Brak portu COM w menu Narzędzia → Port

    • Przyczyna 1: Twój kabel USB służy tylko do ładowania telefonu i nie przesyła danych. Wymień kabel na inny.
    • Przyczyna 2: Brak sterowników do konwertera USB-Serial na płytce. W zależności od wersji płytki deweloperskiej, zainstaluj sterowniki do układów CH340 lub CP2102 (dostępne na stronach producentów tych układów).

    3. Kompilator zgłasza błąd podczas wgrywania (Timeout / Failed to connect)

    • Rozwiązanie: Czasami automatyczny reset płytki w tryb programowania zawodzi. Możesz go wymusić ręcznie:
    • Kliknij przycisk Wgraj w Arduino IDE.
    • Gdy w konsoli pojawi się linijka zaczynająca się od Connecting..., wciśnij i przytrzymaj przycisk BOOT na fizycznej płytce ESP32.
    • W czasie trzymania przycisku BOOT, kliknij raz krótko przycisk RST (Reset).
    • Puść przycisk BOOT. Płytka powinna natychmiast połączyć się i rozpocząć wgrywanie. Kolejne wgrania powinny odbywać się już automatycznie bez tej procedury.
