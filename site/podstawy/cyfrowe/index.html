    Wstęp do IO: Cyfrowe wyjścia i wejścia

    Potrzebujesz: 🔌 ESP32-C6, Kabel USB, Płytka stykowa (Breadboard), Przewody jumper, LED × 2, Rezystor 220–330 Ω × 2, Przycisk tact switch × 1.

    Witamy w sekcji praktycznej! W tym dziale nauczysz się jak składać własne obwody elektryczne, jak rozmawiać z komputerem i jak w pełni operować sygnałem cyfrowym – czyli układem "WŁĄCZONY" / "WYŁĄCZONY".

    Lekcja: Płytka stykowa (Breadboard) i Elektronika

    Zanim zaczniesz wciskać nóżki diod w losowe dziurki w białej płytce, musisz zrozumieć jak ona działa. Płytka stykowa (Breadboard) pozwala łączyć elementy elektryczne bez konieczności lutowania. Posiada tory przewodzące puszczone pod warstwą plastiku, które tworzą z poszczególnych otworów całe połączone bloki (węzły).

    Budowa płytki

       A B C D E   F G H I J
1  o-o-o-o-o   o-o-o-o-o
2  o-o-o-o-o   o-o-o-o-o   ← w jednym rzędzie (np. 1A–1E) wszystkie otwory
3  o-o-o-o-o   o-o-o-o-o     są ze sobą fizycznie zwarte blaszką
4  o-o-o-o-o   o-o-o-o-o
...
+  + + + + + + + + + + +   ← magistrala "+" (zasilanie, u nas 3.3V)
-  - - - - - - - - - - -   ← magistrala "-" (masa, GND, 0V)

    Zasady są proste:

    1. Każdy rząd 5 otworów (np. od 1A do 1E) to połączony przewód. Wpięcie tam dwóch nóżek elementów to tak, jakbyś zlutował je razem.
    2. Rowek pośrodku płytki to izolator – rząd 1A-1E NIE JEST połączony z rzędem 1F-1J.
    3. Krawędzie to magistrale – łączą w długich rzędach całą kolumnę "plusową" i "minusową". Niezbędne by łatwo rozprowadzić wspólne zasilanie.

    Ćwiczenie 1 – Serial: „Witaj świecie!"

    Do komunikacji z komputerem służy wbudowany w mikrokontroler port szeregowy, reprezentowany w kodzie przez obiekt Serial. Aby móc z niego korzystać, musimy poznać podstawowe funkcje: * Serial.begin(prędkość): Uruchamia komunikację z komputerem. Prędkość (baud rate) określa, jak szybko płyną bity. Zazwyczaj stosujemy standardowe 115200. Funkcję tę wywołujemy jednorazowo w bloku setup(). * Serial.println(tekst): Wysyła tekst lub wartość zmiennej do komputera i automatycznie przechodzi do nowej linii (dodaje znak Enter). * Serial.print(tekst): Działa identycznie jak println(), ale nie przechodzi do nowej linii – kolejny komunikat pojawi się bezpośrednio za nim. * delay(czas_ms): Wstrzymuje (zamraża) wykonywanie programu na określoną liczbę milisekund (1 sekunda = 1000 ms).

    1. Podłącz czyste ESP32-C6 za pomocą USB do komputera.
    void setup() {
  // Otwarcie portu komunikacyjnego. Ważne: prędkość musi być równa 115200!
  Serial.begin(115200);

  // Ta funkcja wyśle się TYLKO RAZ po zasileniu, bo jest w bloku "setup"
  Serial.println("Rozpoczynam misję ESP32!");
}

void loop() {
  // Pętla 'loop' obraca się w nieskończoność
  Serial.println("Cześć! Działam wciąż poprawnie!");

  // Wymuszamy "pauzę" na działanie procesora o 1000 milisekund (1 sekunda)
  delay(1000);
}

    Wciśnij ikonę wgrywania (Ctrl + U), a w IDE z menu górnego wybierz Lupa z prawej strony (Monitor Szeregowy). Skontroluj w rogu jego okienka czy prędkość (baud rate) jest ustawiona na 115200.

    Zadanie: Licznik

    Zmodyfikuj kod. Dodaj na samym początku pliku (poza jakimkolwiek blokiem, czyli tzw. zmienną globalną) linię: int licznik = 0;. Zrób z niej licznik odliczający sekundy i wypisujący go w Serial Monitorze wraz ze stałym komunikatem.

    Pokaż rozwiązanie 
    int licznik = 0;

void setup() {
  Serial.begin(115200);
  Serial.println("Rozpoczynam odliczanie!");
}

void loop() {
  licznik++; // Skrót od: licznik = licznik + 1

  Serial.print("Sekunda nr: "); // używamy .print aby nie stawiać znaku "entera"
  Serial.println(licznik);      // a przy wartości używamy .println aby po niej był "enter"

  delay(1000);
}

    Ćwiczenie 2 – Wyjście cyfrowe: LED

    Aby sterować diodą LED, musimy wysłać napięcie z pinu GPIO. W tym celu korzystamy z dwóch kluczowych funkcji: * pinMode(pin, tryb): Konfiguruje dany pin do pracy. Jako tryb podajemy OUTPUT (wyjście, gdy chcemy sterować prądem) lub INPUT (wejście, gdy czytamy dane). Tę konfigurację wywołujemy raz w setup(). * digitalWrite(pin, stan): Ustawia stan napięcia na skonfigurowanym wyjściu. Możemy podać stan HIGH (podaje pełne napięcie 3.3V) lub LOW (podaje masę 0V, wyłączając zasilanie).

    Nadeszła pora na prawdziwy prąd. Zbuduj na breadboardzie układ z diodą LED.

    Dioda przepuszcza prąd i świeci tylko w jednym kierunku! Dłuższa nóżka to anoda (+) - musi iść w stronę wyższego napięcia. Krótsza nóżka to katoda (-) - idzie w stronę GND (masy, zera volt).

    Prawo Ohma i Rezystor!

    Nigdy nie wciskaj gołej diody pod zasilanie bez elementu oporowego. Dioda pobierze tyle prądu, aż całkowicie spali sobie złącze p-n z powodu nadmiaru ciepła. Zawsze używaj rezystora (opornika) wpiętego w szereg, np. 220 Ω, by zmniejszyć przepływający prąd.

    Podłączenie: 

    ESP32 GPIO 2 -> Rezystor -> Dłuższa nóżka diody LED
Masa (GND) z ESP32 -> Krótsza nóżka diody LED

    🎯 [Otwórz Wokwi dla tego obwodu - ZOBACZ JAK ZROBIONO TO NA BREADBOARDZIE] (tutaj pojawi się docelowy link z wirtualnym układem)

    // Przypisanie numerowi 2 fajnie czytającej się etykiety.
const int PIN_LED = 2;

void setup() {
  // "Panie procesorze, od teraz ten kawałek krzemu służy jako elektrownia i MY wydajemy z niego napięcie!"
  pinMode(PIN_LED, OUTPUT);
}

void loop() {
  // /* TUTAJ WSTAW FUNKCJE USTAWIAJACĄ STAN WYSOKI (HIGH) NA PIN */
  /* ??? */(PIN_LED, HIGH);

  delay(500); 

  // /* TUTAJ WSTAW FUNKCJE USTAWIAJACĄ STAN NISKI (LOW) NA PIN */
  /* ??? */(PIN_LED, LOW);

  delay(500); 
}

    Zadanie: Naprzemienne światła alarmowe

    Dołóż drugą diodę z jej osobnym rezystorem na nowym rzędzie breadboarda i podłącz jej anodę pod np. port GPIO 3. Spraw, aby jedna dioda zapalała się tylko w momencie gdy druga gaśnie, przypominając sygnały ostrzegawcze na przejeździe.

    Pokaż rozwiązanie 
    const int PIN_LED1 = 2;
const int PIN_LED2 = 3;

void setup() {
  pinMode(PIN_LED1, OUTPUT);
  pinMode(PIN_LED2, OUTPUT);
}

void loop() {
  digitalWrite(PIN_LED1, HIGH);
  digitalWrite(PIN_LED2, LOW);
  delay(300);

  digitalWrite(PIN_LED1, LOW);
  digitalWrite(PIN_LED2, HIGH);
  delay(300);
}

    Ćwiczenie 3 – Wejście cyfrowe: Przycisk

    Do tej pory procesor "gadał", wysyłając napięcie na zewnątrz. Teraz każemy mu go "słuchać". Aby odczytać stan zewnętrznego przełącznika (przycisku), potrzebujemy: * pinMode(pin, INPUT_PULLUP): Konfiguruje pin jako wejście i jednocześnie aktywuje wbudowany w mikrokontroler wewnętrzny rezystor podciągający do 3.3V (pull-up). Dzięki temu pin nie "wisi w powietrzu" (co dawałoby losowe odczyty zakłóceń elektromagnetycznych), lecz ma stabilny stan wysoki (HIGH), gdy przycisk jest zwolniony. * digitalRead(pin): Odczytuje aktualny stan logiczny na danym pinie. Zwraca wartość HIGH (3.3V) lub LOW (0V).

    Użyjemy mechanicznego przełącznika tact switch. Ponieważ wbudowany rezystor podciąga linię do 3.3V, przycisk podłączamy tak, aby jego wciśnięcie zwierało pin z masą (GND). Oznacza to, że logika przycisku w programie będzie odwrócona: * Przycisk puszczony → odczytujemy stan HIGH * Przycisk wciśnięty → odczytujemy stan LOW

    Podłączenie: 

    ESP32 GPIO 9 -> Lewa dolna noga przycisku
Masa (GND) z ESP32 -> Lewa górna noga przycisku
    (przyciski tego typu mają lewe nogi złączone wewnętrznie, i prawe też złączone wewnętrznie. Naciśnięcie zwiera lewą stronę z prawą).

    🎯 [Otwórz Wokwi z układem przycisku i LED] (tutaj pojawi się wirtualny układ)

    Zadanie - zadeklaruj, odczytuj w pętli digitalRead(PIN_BTN) i zapal diodę wtedy, kiedy jej odczyt spadnie do LOW:

    const int PIN_BTN = 9;   // Pin przycisku
const int PIN_LED = 2;   // Pin LED z poprzednich ćwiczeń

void setup() {
  pinMode(PIN_LED, OUTPUT);

  // Zamiast INPUT używamy INPUT_PULLUP, by załączyć wbudowany opornik podciągający do 3.3V
  pinMode(PIN_BTN, INPUT_PULLUP);
}

void loop() {
  // Odczyt aktualnego stanu z wbudowanego "nasłuchiwania" GPIO
  int aktualny_stan = digitalRead(PIN_BTN);

  if (aktualny_stan == LOW) {  // Pamiętaj! W Pullupie LOW oznacza naciśnięty!
     /* ??? ZAPAL DIODE Z POPRZEDNIEGO ZADANIA ??? */
  } else {
     /* ??? ZGAS DIODE ??? */
  }

  delay(20); // Drobne opóźnienie dla stabilności (odciąża procesor i ignoruje delikatnie drgające blaszki styku w przycisku).
}

    Zadanie do samodzielnego wykonania: Reagowanie na zmianę

    Przerób powyższy kod tak, aby jedno naciśnięcie (i PUSZCZENIE) klawisza ZAPALIŁO diodę na stałe (przestało reagować), a wciśnięcie jeszcze raz spowodowało całkowite zgaszenie (taki pstryczek on/off dla oświetlenia domu). Uwaga: to wyjątkowo bardzo trudne i skomplikowane algorytmicznie zadanie! Zastanów się, czy sprawdzając warunek w tak potężnie szybkiej pętli, jeśli tylko powiesz układom, aby np. zrobili wlaczone = !wlaczone, to czy zrobienie tego 10 000 razy w ułamku sekundy, w którym zwierałeś fizyczny plastik, nie popsuje pomysłu! (Odpowiedź: popsuje).

    Pokaż rozwiązanie Algorytm wymaga dwóch zmiennych: zapamiętania poprzedniego i obecnego cyklu pętli aby sprawdzić słynne "Zwieranie/Puszczanie", a nie sam akt trzymania przycisku. To tzw. zjawisko *zbocza opadającego*. 
    const int PIN_BTN = 9;
const int PIN_LED = 2;

int poprzedni_stan = HIGH;  // przed odpaleniem w spoczynku jest HIGH (pullup)
int stan_diody = LOW;

void setup() {
  pinMode(PIN_BTN, INPUT_PULLUP);
  pinMode(PIN_LED, OUTPUT);
}

void loop() {
  int obecny_stan = digitalRead(PIN_BTN);

  // Jeśli przycisk W TEJ milisekundzie został wciśnięty (jest teraz niski), ale W ZESZŁEJ milisekundzie jeszcze nie był:
  if (obecny_stan == LOW && poprzedni_stan == HIGH) {

      if (stan_diody == LOW) {
         stan_diody = HIGH;
      } else {
         stan_diody = LOW;
      }
      digitalWrite(PIN_LED, stan_diody);

      // bardzo ważne sprzętowo zabezpieczenie przed podskakującymi blaszkami (tzw debouncing):
      delay(50);
  }

  poprzedni_stan = obecny_stan;
}
