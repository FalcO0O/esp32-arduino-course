    Wi-Fi: Serwer i Klient

    Potrzebujesz: 📱 Smartfon lub laptop z Wi-Fi (do połączenia z serwerem) oraz hotspot (do podłączenia ESP32 do internetu).

    Układ ESP32-C6 umożliwia komunikację z siecią lokalną oraz globalną siecią Internet. Może działać jako serwer prezentujący dane w przeglądarce użytkownika lub jako klient pobierający informacje z chmury.

    🌐 Stos sieciowy Wi-Fi w ESP32

    Komunikacja Wi-Fi opiera się na warstwowej strukturze (stosie sieciowym). Zrozumienie, jak te warstwy ze sobą współpracują, pomaga pisać stabilniejszy kod:

    • Warstwa fizyczna (PHY/RF): Odpowiada za modulację sygnału radiowego w pasmie 2.4 GHz, moc nadawania, odbiór fal antenowych oraz wybór fizycznego kanału radiowego (częstotliwości).
    • Warstwa łącza danych (MAC / 802.11): Odpowiada za strukturę ramek 802.11, kontrolę dostępu do medium radiowego, uwierzytelnianie oraz szyfrowanie (np. WPA2/WPA3). Wykorzystuje unikalny adres fizyczny MAC urządzenia.
    • Warstwa sieciowa i transportowa (TCP/IP - lwIP): ESP32 wykorzystuje lekki i zoptymalizowany stos lwIP (Lightweight IP). Odpowiada on za przydzielanie adresów IP (DHCP), routing, rozwiązywanie nazw domen (DNS) oraz przesyłanie pakietów przez protokoły TCP i UDP.
    • Warstwa aplikacji: Kod użytkownika oraz biblioteki Arduino (np. <WebServer.h>, <HTTPClient.h>), które przetwarzają żądania HTTP, serwują pliki HTML lub wysyłają zapytania do zewnętrznych serwerów.

    📶 Tryby pracy Wi-Fi

    ESP32 może pracować w różnych trybach radiowych:

    • Station (Tryb stacji - WIFI_STA): Mikrokontroler łączy się z istniejącą siecią Wi-Fi (np. z domowym routerem lub hotspotem w telefonie) jako klient. Otrzymuje adres IP z routera i ma dostęp do innych urządzeń w tej samej sieci oraz do Internetu.
    • Access Point (Punkt dostępowy - WIFI_AP): ESP32 tworzy własną sieć bezprzewodową o zadanej nazwie (SSID) i haśle. Inne urządzenia (np. smartfon) mogą połączyć się bezpośrednio z ESP32. W tym trybie ESP32 domyślnie przydziela podłączonym urządzeniom adresy IP z puli 192.168.4.X.

    🎯 Ćwiczenie 1: Wi-Fi Access Point (Własny Serwer WWW)

    W tym ćwiczeniu ESP32-C6 wykreuje własną sieć bezprzewodową (tryb Access Point) i uruchomi serwer HTTP. Po połączeniu ze smartfona lub laptopa będziesz mógł sterować wbudowaną diodą LED za pomocą prostej strony internetowej.

    Wykorzystamy również usługę mDNS (multicast DNS), aby serwer był dostępny pod przyjazną nazwą tekstową (np. http://moje_esp.local) zamiast surowego adresu IP 192.168.4.1.

    Obsługa mDNS na smartfonach

    System Android domyślnie nie wspiera mDNS bez dodatkowego oprogramowania. Jeśli testujesz układ na telefonie z Androidem, połącz się z siecią ESP i w przeglądarce wpisz surowy adres IP: http://192.168.4.1. Na systemach iOS, macOS oraz Windows adres http://moje_esp.local powinien zadziałać automatycznie.

    Kod programu

    #include <WiFi.h>
#include <WebServer.h>
#include <ESPmDNS.h>

const int PIN_LED = 2;

// ZMIEŃ nazwę sieci na unikalną (np. dodaj swoje inicjały)
const char* nazwaSieci = "ESP32_Sterowanie_AP";
const char* hasloSieci = "12345678"; // Hasło musi mieć minimum 8 znaków

// Uruchamiamy serwer na standardowym porcie HTTP: 80
WebServer server(80);

// Strona HTML przechowywana w pamięci flash (PROGMEM)
const char STRONA_HTML[] PROGMEM = R"rawliteral(
<!DOCTYPE html>
<html lang="pl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <style>
    body { background: #1e1e2f; color: #fff; font-family: sans-serif; text-align: center; padding-top: 50px; }
    button { background: #ff6b6b; padding: 15px; font-size: 18px; cursor: pointer; width: 80%; max-width: 300px; margin: 10px; border: none; border-radius: 5px; color: white; }
    button.off { background: #4e4e5e; }
  </style>
</head>
<body>
    <h2>Sterowanie ESP32</h2>
    <p>Wybierz akcję:</p>
    <button onclick="location.href='/on'">Włącz LED</button>
    <button class="off" onclick="location.href='/off'">Wyłącz LED</button>
</body>
</html>
)rawliteral";

void setup() {
  Serial.begin(115200);
  pinMode(PIN_LED, OUTPUT);

  // Uruchomienie punktu dostępowego
  WiFi.softAP(nazwaSieci, hasloSieci);
  Serial.println("\n--- Wi-Fi Access Point Uruchomiony ---");
  Serial.print("Nazwa sieci (SSID): "); Serial.println(nazwaSieci);
  Serial.print("Adres IP serwera: "); Serial.println(WiFi.softAPIP());

  // Inicjalizacja domeny lokalnej moje_esp.local
  if (MDNS.begin("moje_esp")) {
    Serial.println("Serwer mDNS uruchomiony. Adres: http://moje_esp.local");
  }

  // Definiowanie tras (ścieżek) serwera:

  // Strona główna serwuje przygotowany dokument HTML
  server.on("/", []() {
    server.send(200, "text/html", STRONA_HTML);
  });

  // Włączenie diody i przekierowanie z powrotem na stronę główną
  server.on("/on", []() {
    digitalWrite(PIN_LED, HIGH);
    server.sendHeader("Location", "/");
    server.send(303); // HTTP Status 303: See Other
  });

  // Wyłączenie diody i przekierowanie z powrotem na stronę główną
  server.on("/off", []() {
    digitalWrite(PIN_LED, LOW);
    server.sendHeader("Location", "/");
    server.send(303);
  });

  // Start serwera
  server.begin();
  Serial.println("Serwer HTTP oczekuje na połączenia...");
}

void loop() {
  // Przetwarzanie nadchodzących żądań klientów Wi-Fi
  server.handleClient();
}

    🎯 Ćwiczenie 2: Wi-Fi Client (Pobieranie danych JSON z zewnętrznego API)

    W tym ćwiczeniu ESP32 połączy się z zewnętrzną siecią Wi-Fi (np. hotspotem z telefonu) w trybie Station. Następnie wyśle zapytanie HTTP GET do publicznego interfejsu API i odbierze losową ciekawostkę.

    Dane z API są przesyłane w formacie JSON (JavaScript Object Notation). Do ich przeanalizowania (odkodowania) wykorzystamy popularną bibliotekę ArduinoJson.

    Wymagana biblioteka: ArduinoJson

    Przed wgraniem kodu zainstaluj bibliotekę w środowisku programistycznym:

    1. W Arduino IDE przejdź do: Library Manager (zarządca bibliotek).
    2. Wyszukaj i zainstaluj bibliotekę ArduinoJson (autorstwa Benoit Blanchon).

    Kod programu

    #include <WiFi.h>
#include <HTTPClient.h> // Biblioteka obsługująca zapytania HTTP
#include <ArduinoJson.h> // Biblioteka do obsługi formatu JSON

// UZUPEŁNIJ: wpisz dane swojej sieci Wi-Fi (np. hotspotu z telefonu)
const char* ssid     = "NAZWA_TWOJEJ_SIECI";
const char* password = "HASLO_TWOJEJ_SIECI";

// Publiczne API zwracające losowe fakty w formacie JSON
const char* urlAPI = "https://uselessfacts.jsph.pl/api/v2/facts/random";

void setup() {
  Serial.begin(115200);

  // Konfiguracja ESP32 jako stacji (klienta)
  WiFi.mode(WIFI_STA);
  WiFi.begin(ssid, password);

  Serial.print("Łączenie z siecią Wi-Fi");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nPołączono pomyślnie!");
  Serial.print("Uzyskany adres IP: ");
  Serial.println(WiFi.localIP());
}

void loop() {
  // Sprawdzenie stanu połączenia z siecią
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;

    // Inicjalizacja połączenia z adresem API
    http.begin(urlAPI);

    // Wysłanie żądania HTTP GET
    int httpResponseCode = http.GET();

    // Sprawdzenie, czy serwer odpowiedział poprawnie (kod 200)
    if (httpResponseCode == HTTP_CODE_OK) {
      String response = http.getString();

      // Dynamiczna alokacja dokumentu JSON
      JsonDocument doc;

      // Deserializacja (parsowanie) odebranego tekstu JSON
      DeserializationError error = deserializeJson(doc, response);

      if (error == DeserializationError::Ok) {
        Serial.println("\n==================================================");
        Serial.print("Losowy fakt: ");
        // Wyciągnięcie wartości dla klucza "text" ze struktury JSON
        Serial.println(doc["text"].as<String>());
        Serial.println("==================================================");
      } else {
        Serial.print("Błąd parsowania JSON: ");
        Serial.println(error.c_str());
      }
    } else {
      Serial.print("Błąd żądania HTTP. Kod błędu: ");
      Serial.println(httpResponseCode);
    }

    // Zwolnienie zasobów połączenia HTTP
    http.end();
  } else {
    Serial.println("Brak połączenia z siecią Wi-Fi!");
  }

  // Odczekaj 10 sekund przed kolejnym zapytaniem
  delay(10000);
}
